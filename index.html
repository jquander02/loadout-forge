Bring in your gear

Export two spreadsheets from Destiny Item Manager and drop them here. Files are read in your browser and never uploaded.

  1. Open DIM and sign in.
  2. Go to Settings (gear icon) → Spreadsheets, or the Organizer's export button.
  3. Download Armor and Weapons CSVs.
  4. Drop both files below. Re-import any time your vault changes.

Sending results back to DIM

The Armor tab builds a tags file (Id, Hash, Tag, Notes) for DIM's Import tags/notes from CSV button in Settings. Saved loadouts copy a DIM search string, so you can select the pieces in DIM and save them as a DIM loadout.

Armor review

Outclassed means another piece of the same slot, class, set and exotic has every stat equal or higher and is at least the same gear tier. Keep everything else until you've run a few builds.

Weapons

Copies of the same weapon are ranked by gear tier, crafted status, your DIM tag and power. Perks shown bright are the ones currently selected. Roll quality is your call: compare the perks before dismantling.

Settings

1 · Bungie API key

Needed to look up item names and where items come from. It's free and takes a few minutes.

  1. Sign in at bungie.net/en/Application and choose Create New App.
  2. Any name works. Set OAuth Client Type to Not Applicable.
  3. Set Origin Header to http://localhost:7777.
  4. Agree to the terms, create the app, and copy its API Key here.

2 · DIM API key

Needed only for dim.gg links. DIM gives development keys to anyone with a Bungie key, so this is one click.

Paste a key instead

3 · Item database

A copy of Bungie's item list, kept on this PC. Download it once, then update after big game patches. It's a large download and takes a minute or two.
